## О проекте

В репозитории собраны:

- лабораторные работы `lab_1` ... `lab_8`;
- папка `ргр` (черновая структура многостраничного Streamlit-проекта);
- папка `ргр_streamlit` (основная рабочая версия приложения для РГР).

Основная предметная область: прогноз сердечно-сосудистых заболеваний по клиническим признакам.

## Структура репозитория

```text
.
├── lab_1/                  # Базовые задачи регрессии и классификации + EDA
├── lab_2/                  # Линейные модели, регуляризация, полиномиальные признаки
├── lab_3/                  # KNN, собственные метрики, кастомный классификатор
├── lab_4/                  # Деревья решений, ансамбли, бустинги, стекинг
├── lab_5/                  # Кластеризация (K-means, DBSCAN, HDBSCAN и др.)
├── lab_6/                  # Понижение размерности (задание и материалы)
├── lab_7/                  # Полносвязные НС (задание и материалы)
├── lab_8/                  # CNN и transfer learning (задание и материалы)
├── ргр/                    # Черновая версия RGR-приложения (частично пустые страницы)
└── ргр_streamlit/          # Основное Streamlit-приложение + обученные модели
```

### Ключевые файлы

- `lab_3/my_knn.py` — простая реализация KNN (Manhattan distance).
- `lab_3/personal_knn.py` — sklearn-совместимый класс `KNNClassifier`.
- `lab_3/custom_metrics.py` — ручной расчет `Accuracy`, `Precision`, `Recall`, `F1`.
- `ргр_streamlit/Home_page.py` — единая точка входа в Streamlit-приложение.
- `ргр_streamlit/requirements.txt` — зависимости для запуска приложения.

## Быстрый старт (Streamlit-приложение)

Ниже запуск **основной** версии из папки `ргр_streamlit`.

### 1. Подготовить окружение

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r "ргр_streamlit/requirements.txt"
```

### 2. Запустить приложение

```bash
cd "ргр_streamlit"
streamlit run Home_page.py
```

После запуска откройте URL из терминала (обычно `http://localhost:8501`).

## Что умеет приложение

Разделы в интерфейсе:

- `Информация` — автор, тема и общая справка.
- `Данные` — описание признаков, EDA и просмотр датасета.
- `Визуализация` — графики распределений и корреляций.
- `Предсказание` — инференс по выбранной модели.

Поддерживаемые модели:

- `KNN`
- `Gradient Boosting`
- `CatBoost`
- `Random Forest`
- `Stacking`
- `Neural Network` (`model_nn.h5` + `nn_preprocessor.pkl`)

Форматы предсказания:

- пакетный (загрузка `CSV`);
- ручной (ввод признаков через форму).

## Работа с лабораторными

Лабораторные оформлены в основном в формате Jupyter Notebook (`.ipynb`).

Рекомендуемый порядок изучения:

1. `lab_1` → `lab_2` → `lab_3` → `lab_4` → `lab_5`
2. затем задания повышенной сложности: `lab_6`, `lab_7`, `lab_8`

Чтобы работать с ноутбуками:

```bash
source .venv/bin/activate
jupyter notebook
```

Примечание: часть ноутбуков использует дополнительные библиотеки (например, бустинги/AutoML/гиперпараметрический поиск), которые могут отсутствовать в `ргр_streamlit/requirements.txt`.
